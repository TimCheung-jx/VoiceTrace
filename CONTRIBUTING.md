# Contributing

1. Keep the change focused and preserve meeting-format compatibility where practical.
2. Use only fictional fixtures. Never contribute private recordings, meeting content, personal profiles, or credentials.
3. Run `./测试.command` and `python3 scripts/audit.py --staged`.
4. For UI changes, check the relevant native screens and reduced-motion behavior.
5. Submit a pull request describing the user-visible behavior and validation.

Contributions are accepted under the project's MIT License.
