# 声迹VoiceTrace — 0.13.1

原生 Mac 会议工作台。0.13沿用0.12的本机资料库和服务配置；0.10资料可通过“导入旧版会议资料”迁移。

## 本次更新

### 0.13.1 稳定性修复

- 音频引擎启动在工作队列进行。本地采集就绪后即开始录音，凭据读取和识别连接异步进行；开头音频短暂缓冲，避免因读取凭据阻塞录音。
- 配置变化时先判断引擎及格式，稳定通知不暂停；实际变化采用受限恢复。持续没有音频缓冲也进入恢复，失败会保留诊断并安全暂停。
- 改写分包PCM转换路径，使用有界连续相位的抗混叠重采样；离线测试覆盖8–192kHz、常见声道及格式切换、空输入和异常数值。
- 问答改为本机保存的连续对话。提交后立即清空输入框，问题与回答分别呈现，回答不会覆盖下一条正在输入的问题。
- 未定稿只显示数量，默认收起。可以关闭提示，或在独立窗口按需展开；原有临时文字继续保留。
- 启动诊断仅保存白名单阶段、相对耗时、数字错误码，最多32阶段。后台有序写盘，不作为启动前置步骤；入口为“资料与历史→录音启动诊断”。
- 实际麦克风／蓝牙切换及云端识别延迟仍需短试录核对，模拟通过不等于用户设备验收通过。豆包接入按确认安排在稳定性修复之后。

### 已有功能


- 独立的总览、原文、观点图、会议纪要、待办清单及笔记页面。每页固定显示复制、下载、分享；观点图复制包含图片和文字，下载支持PNG/SVG，文字成果支持Word/PDF/Markdown/纯文本。
- 分享在本机生成文件，再打开Mac系统分享面板，由用户选择服务；也可下载后拖入微信或钉钉。可用服务取决于本机安装的分享扩展。
- 会议库增加勾选框、全选、批量移入最近删除和逐项重命名；最近删除可恢复。点击名称打开会议，点击铅笔编辑名称。
- 清理新建和切换会议时的临时文字；中断时尚未定稿的文字单独保存，不计入正式原文和AI分析。
- 显示输入音量、识别连接、最近回字时间。检测到声音但30秒没有识别结果时尝试重连；每段录音最多自动尝试3次，间隔1/3/8秒，可手动重新连接。本地录音继续；断线片段需会后补转写，当前没有自动补传。
- 设置提供断句速度与轻声识别选项。轻声选项可能增加噪音转写；识别准确度和真实延迟仍需实际试录。参数依据见文末官方文档。
- AI问答有明确文字入口、快捷问题、取消和回答PDF导出。问答不锁住会议切换，切换时取消旧请求并隔离迟到回答。
- 个人版应用名称为“声迹VoiceTrace”，紫色图标；安装包为 `outputs/VoiceTrace-0.13.1-personal.zip`，清洁版为 `outputs/VoiceTrace-0.13.1-clean.zip`。个人版沿用本机钥匙串；密钥不嵌入安装包。

## 结构

- `Sources/Core`：类型化会议、来源引用、成果校验、关系图布局、SQLite事务和异常录音恢复。
- `Sources/App`：新工作台、录音服务协调、图形交互、服务设置及导出。
- `Fixtures`：完全虚构的接口响应；只用于验收。
- `Tests`：服务响应解包、持久化重开、局部失败、引用关系、迁移及恢复测试。
- 旧版只有 `Protocol / Configurations / MemoryCredentials / Services / Audio` 五个底层文件参与适配。旧 Workspace 和旧 UI 不参与构建。

## 构建与测试

在项目根目录执行：

```sh
./Next/test.command
./Next/test-workspace.command
./Next/test-audio.command
./Next/test-export.command
VTNEXT_UNIVERSAL=1 ./Next/build.command personal
VTNEXT_UNIVERSAL=1 ./Next/build.command clean
```

默认构建无预置凭据的清洁版、本机架构；设置 `VTNEXT_UNIVERSAL=1` 构建 Intel / Apple 芯片通用包。最低 macOS 13。使用系统 SwiftUI、AppKit、AVFoundation、SQLite 与钥匙串，没有 Web/CDN 运行依赖。当前为本地临时签名，尚未完成正式公证发行。

## 使用

1. 解压安装包，将“声迹VoiceTrace”放入应用程序，可与旧版同时保留。录音时只运行一个版本，避免竞争输入设备。
2. 个人版尝试读取旧版非敏感服务配置，密钥仍从原钥匙串账户获取，未嵌入安装包。清洁版使用独立命名空间，需要自行设置。
3. 旧会议通过“资料与历史→导入旧版会议资料”复制到新资料库。请选择包含各会议子目录的总目录；原文件不变，重复导入不会重复建会。
4. 导入会议后点击“整理会议”，生成新结构。旧文字会折叠保留，不能直接把旧段落称为已生成图形。
5. “观点图”支持滚动平移、缩放、适应窗口、发言人筛选、分歧筛选和右键收起分支。点击节点查看完整内容、原文与回听位置。
6. “待办清单”中可勾选任务；不明负责人和期限明确显示待确认。已完成状态保存在本机并进入文字导出。
7. 使用导出菜单复制或下载成果；分享文件可拖入微信或钉钉，应用不会替您发送消息。
8. 设置中“保存配置并用虚构会议验证完整整理”会创建独立虚构会议，经真实所选API验证解析、保存和绘图。该操作需要密钥并可能产生服务费用，不发送已有真实会议。

## 两种验收，不混称

“查看虚构流程验收”：固定服务响应经过与生产相同的响应解包、校验及存储入口，重开后绘图。它验证工程链路，不验证真实模型内容质量。

“用虚构会议验证完整整理”：调用真实所选整理服务。结果仍需对照虚构原文核对。只有实际执行后才能记录真实云端集成通过。

## 数据和限制

- 个人版默认资料库：用户“资源库/Application Support/VoiceTrace Next Personal”；清洁版使用“VoiceTrace Next”。音频、原文、修订和缓存不额外加密。
- 本地采集先写盘，网络识别失败时录音继续。识别异常会有限重连；中断片段需结束后手动补转写。
- “恢复中断录音”恢复已写盘的PCM部分，保留原件；不会自动上传。
- 会后补转写会创建原文修订备份。跨录音段发言人身份仍需人工核对，模型不会自行猜姓名。
- 无时间戳的纯文本使用“第N段”引用，不能冒充真实音频时间。
- 图形节点显示摘要，完整内容可点击查看；完整文字另用Markdown/PDF导出。大图可优先选择SVG。
- 现阶段最近删除保留资料；不自动永久清除文件。会议问答只读取有限原文片段，不能视为全文穷尽检索。
- 真实麦克风、耳机切换、长时间录音、云端识别质量及模型归纳质量尚需实测。工程模拟测试不代表这些项目已通过。
- 当前没有安排外部独立工程师或用户评审，不将开发自检称为独立认证。
