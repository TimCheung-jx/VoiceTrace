# 声迹VoiceTrace

**原生 macOS AI 会议工作台：录音、实时转写、可追溯纪要与观点图。**

## 简介

声迹VoiceTrace 使用 SwiftUI、AppKit 与系统音频能力构建。会议资料保存在本机，普通话实时识别与会议整理通过用户配置的云端 API 完成，无需安装本地大模型。

当前版本为 **0.13.1 测试版**，支持 Intel 和 Apple 芯片 Mac。公开源码与清洁版不含作者的 API Key、Workspace ID、私人配置或真实会议资料。截图与测试全部使用虚构内容。

## 功能

- **录音与实时原文**：开始、暂停、继续、结束；本地音频保存、回听、输入音量、声波、识别状态和最近回字时间。先启动本地采集，再后台读取凭据与连接识别。
- **发言人**：有声音区分结果时以“发言人1、2…”标记，用户可统一改名。无法区分时保留未知身份，不猜测姓名；跨录音段身份仍需核对。
- **会议成果**：总览、原文、观点图、会议纪要、待办清单、笔记。章节与原文时间定位结合；观点、决定、任务等关联来源片段。
- **真正的观点图**：节点、方向连线与关系标签，支持缩放、适应窗口、按发言人／分歧筛选、收起分支；点击节点查看完整内容和原文。
- **纪要与待办**：结构化分组，区分决定、建议与待确认事项；负责人和期限不明时明确标记，任务完成状态可保存。
- **持续整理与问答**：录音中周期整理及结束后整理可分别关闭；问答支持连续对话，提交后立即清空输入框，聊天记录随会议保存。
- **会议库**：搜索、逐项重命名、显式勾选、全选、批量移入最近删除及恢复。
- **复制、下载与分享**：各主要页面提供固定入口，文字支持 Word / PDF / Markdown / TXT，观点图支持 PNG / SVG；通过 macOS 分享面板由用户选择服务，也可下载后拖入微信或钉钉。
- **恢复与诊断**：识别异常有限重连，同时继续本地录音；未定稿默认收起且可关闭提示，原文保留；支持恢复中断录音及导出仅含技术阶段的启动诊断。

## 构建与使用

需要 **macOS 13+、Xcode Command Line Tools、Python 3**。没有第三方 Swift 包、网络字体或 Web 运行依赖。

在仓库根目录执行：

```sh
# 离线测试，不读取真实密钥、不打开麦克风、不调用云端
./测试.command

# 默认构建 Intel / Apple 芯片通用清洁版
./构建.command
```

输出：

```text
outputs/VoiceTrace-0.13.1-clean/声迹VoiceTrace Clean.app
outputs/VoiceTrace-0.13.1-clean.zip
```

解压后将应用放入“应用程序”。当前采用本地临时签名，**尚未进行 Developer ID 公证**，系统可能要求批准启动和麦克风访问；跨版本免钥匙串重复授权没有保证。

当前产品代码在 [`Next/`](Next/README.md)，默认构建不使用旧版工作台界面。`Sources/` 中部分底层协议、配置、钥匙串、服务与音频文件仍被复用；其余旧代码及测试保留用于兼容参考。

### 配置服务

打开“声迹设置”，分别配置语音与整理服务，填写自己的地域、Workspace ID、接口、模型名和 API Key。不要将真实密钥写入源码或提交到 Git。

| 用途 | 已适配接口 |
| --- | --- |
| 实时语音识别 | 阿里云百炼 Fun-ASR-Realtime 及对应版本；北京／新加坡地域 |
| 会后补转写 | 百炼 `fun-asr`、`paraformer-v2`、`qwen-audio-3.0-asr-flash-filetrans` |
| 会议整理与问答 | DeepSeek 官方或 HTTPS Chat Completions 兼容接口，可分别保存多个配置 |

模型可用性、权限和费用取决于服务商。当前语音协议只适配百炼，**豆包尚未接入**，仅修改模型名称不能切换协议。整理和语音可以选择同一服务商，但必须分别具备已适配的接口。

使用流程：配置服务 → 新建会议 → 开始录音 → 结束 → 核对原文、发言人与成果 → 下载或分享。长原文可“跟随最新”或“回到最新”。旧版资料可从“资料与历史 → 导入旧版会议资料”复制导入，原件保留。

## 隐私与数据边界

- API Key 存于 macOS 钥匙串，读取后在当前进程内缓存；不嵌入安装包、不写入诊断。清洁版有独立应用配置和钥匙串账户，不读取个人版的凭据与会议库。
- 清洁版资料库位于 `~/Library/Application Support/VoiceTrace Next`，这个内部目录名用于保持兼容；包含音频、原文、修订、问答及缓存，**没有额外加密**。
- 本地采集先写盘。启用实时识别会向所选语音服务发送音频；整理与提问会向所选文字服务发送相应原文及必要上下文。
- **默认开启周期整理（45秒检查一次）和结束后整理**；可在设置中分别关闭。没有文字服务密钥时不会发起整理请求。关闭自动整理不影响手动整理。
- 启动诊断仅保存白名单阶段、相对毫秒数和数字错误码，最多32阶段；后台写盘，不包含音频、转写、问题或密钥。
- 未定稿不进入正式原文和会议整理输入；关闭提示只隐藏界面，保留文字。移入最近删除保留本机资料，当前不自动永久清除。
- 不自动向微信、钉钉或其他联系人发送资料。选择分享对象和发送由用户完成。

详见 [安全与隐私](SECURITY.md)。

## 验证与限制

已通过离线核心、模拟录音／识别、工作台、合成音频、Word/PDF重开与内容核对，以及通用构建和签名检查。界面截图由清洁版隔离实例读取虚构服务响应，经解析、保存、重开后生成，**不是实际云端识别截图**。

- 仅采集默认麦克风，不采集电脑系统音频。
- 识别断线最多自动重试3次，也可手动重连；本地录音继续。断线缺失片段需会后手动补转写，目前没有自动补传。
- 会后识别依赖服务商临时上传能力；每段两小时／300MB限制及跨段发言人核对仍适用。
- 问答目前最多发送3万字符的原文片段；不能当作全文穷尽搜索。AI结果可能遗漏或误解，重要决定、引用和任务须对照原文核实。
- 真实麦克风、蓝牙／耳机切换、长时间录音、云端延迟和内容质量仍需设备与服务实测。模拟通过不等于这些项目已验收，也不代表独立认证。

详细证据见 [验收记录](Next/docs/ACCEPTANCE.md)，当前界面约定见 [设计说明](docs/DESIGN.md)。
