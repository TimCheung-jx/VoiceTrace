# 声迹 VoiceTrace

**原生 macOS AI 会议工作台：把讨论留下，把分歧说清。**

[English](README.en.md) · [MIT License](LICENSE) · [隐私与安全](SECURITY.md)

![VoiceTrace 工作台，虚构会议示例](docs/images/workspace.png)

## 简介

VoiceTrace 使用 SwiftUI 构建，结合云端语音识别和大语言模型，将会议录音整理成可核对的逐字稿、纪要、讨论脉络和行动事项。面向需要长时间阅读、回听与整理会议的个人用户。

这是可自行构建的测试版，尚未完成所有服务与所有macOS版本的实际兼容测试。

## 功能

- 麦克风实时录音与转写，暂停、继续、本地音频保存和时间回听。
- 会后重新转写并区分发言人；不同录音段中的身份需要人工核对。
- 七个页面：转写、笔记、AI纪要、思维链、分歧点、章节、待办。
- **思维链**：会议议题、各方观点、明确理由、回应与结论的结构化记录，不是模型内部推理。
- **分歧点**：区分明确冲突、执行条件和待确认信息，保留原文时间定位；没有明确冲突时应说明，而不是制造分歧。
- 基于逐字稿的会议问答，可切换多个模型配置。
- 当前页复制、Word/PDF/TXT/Markdown导出、思维链PNG与系统分享。
- 四种主题、可收起的AI助手、轻量动效与系统减少动态效果支持。

## 清洁版本与隐私

**仓库不包含作者的API Key、Workspace ID、私人模型配置、真实录音或会议材料。**使用者必须自行配置服务并承担相应费用。

- API Key保存在macOS钥匙串；成功读取后在本次进程内缓存，不写入源码、偏好设置或日志。
- 清洁版使用独立应用及钥匙串命名空间，不读取旧版个人应用的密钥、偏好设置或会议目录。
- 会议默认保存在 `~/Documents/VoiceTrace`，普通配置保存在应用偏好设置。资料没有额外加密。
- 这不是完全离线的识别工具：启动转写时音频发送至所选语音服务；点击整理或问答时逐字稿发送至所选大模型。
- 不会自动向微信、钉钉或其他联系人发送消息。用户须在系统分享界面确认。
- 截图、内置演示和测试数据均为虚构内容。

## 环境与构建

- macOS 13及以上。
- Xcode Command Line Tools，提供Swift编译器与macOS SDK。
- 不需要安装本地大模型，不需要第三方Swift包。
- 测试及提交审计另需Python 3。

在项目根目录执行：

```sh
./测试.command
./构建.command
```

构建脚本生成Apple芯片与Intel通用应用，并进行本地临时签名：

```text
outputs/声迹 VoiceTrace Clean.app
outputs/VoiceTrace-Mac-0.6.1-Clean.zip
```

解压或将应用拖入“应用程序”后打开。当前构建不是Developer ID公证发行包；正式分发需自行配置稳定签名与Apple公证。操作系统可能要求批准启动或麦克风权限。

## 配置服务

在左下角“设置”→“模型与服务”中分别保存语音和整理配置。

| 用途 | 当前适配 |
|---|---|
| 实时语音 | 阿里云百炼Fun-ASR-Realtime及其版本 |
| 会后语音/发言人 | 百炼 `fun-asr`、`paraformer-v2`、`qwen-audio-3.0-asr-flash-filetrans` |
| 语音地域 | 北京、新加坡；API Key和Workspace ID须属于对应地域 |
| 会议整理 | DeepSeek官方或HTTPS Chat Completions兼容接口 |

模型是否可用、权限和费用取决于服务商账号。配置名称可自定；“测试实时连接”仅验证实时任务握手，“测试整理连接”仅发送固定虚构文字，不能代替完整录音测试。

使用步骤：新建会议 → 开始录音 → 结束 → 可选会后发言人整理 → 整理会议 → 核对 → 导出/分享。

## 已知限制

- 只采集默认麦克风，不采集电脑系统音频。
- 网络中断会停止本段，不自动重连或补传。
- 会后识别使用百炼开发测试临时上传空间，正式生产应换成合适的存储方案。
- 会后单段目前限制为两小时、300MB；跨段发言人编号不自动对齐。
- 本地临时签名不能保证跨版本永久免钥匙串授权。
- AI归纳可能有误，重要结论、引用与任务必须人工核对。
- 兼容接口的返回格式和实际模型能力需自行验证。
