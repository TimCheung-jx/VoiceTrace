# Configuration example / 配置示例

`model-config.example.json` documents the shape of non-secret profile metadata. It is not automatically imported by the app. Configure real services through Settings → Models & Services. API keys are intentionally absent and belong in macOS Keychain only.

此JSON仅展示非敏感配置结构，应用不会自动导入。请通过设置填写真实服务信息；API Key刻意不放入示例文件，仅应保存在系统钥匙串中。
